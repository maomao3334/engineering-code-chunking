# 输出 schema 与切片规范

## 页签 1：语料库（条文级，一条一行）

| 字段 | 类型 | 说明 |
|---|---|---|
| 规范全称 | 字符串 | 用原书名称，不含书名号 |
| 规范编号 | 字符串 | 规范化加空格：`GB 55037-2022` |
| 章 | 字符串 | 章号 + 章标题：`5 建筑结构耐火` |
| 节 | 字符串 | `5.3 民用建筑`；未设节的章统一写 `未设节`，**不得臆造 `0 节`** |
| 条文号 | 字符串 | `5.3.1`。**必须存为文本**，否则 Excel 会转成小数或日期 |
| 条文小标题 | 字符串 | 若为 AI 归纳，必须在「小标题来源」字段注明，**不得作为原文引用** |
| 条文原文本体 | 字符串 | 不含条号；款另起一行带原编号；**不含表格** |
| 是否强条 | 字符串 | 依据公告判定 |
| 条文类型 | 枚举 | 正文 / 术语 / 条文说明 / 附录。PDF 里没有的不要造 |
| PDF起页 / PDF末页 | 整数 | 物理页，非印刷页 |
| 块ID | 字符串 | `编号::条号`，全库唯一。编号去空格 |
| 关联表格 | 字符串 | 该条引用的表号；空表示未引用 |
| 关联附录 | 字符串 | 该条引用的附录号（`附录A`），供"按附录取值"类问题闭环 |
| 引用条文 | 字符串 | 该条提到的其他条号（`第3.2.3条`）；父块切片据此附加被引条文正文（铁律 3） |
| 列项数 | 整数 | 一级款数（不含二级款） |
| 字数 | 整数 | 条文原文本体字符数 |
| 小标题来源 | 字符串 | 空＝原文无小标题；`原文（术语条文自身即术语名）`＝取自原文。**拒绝把归纳标题当原文** |
| OCR最低置信度 | 浮点 | 便于质量追溯（纯文字层可空） |
| 来源行ID | 字符串 | `p015-y873, p015-y961`，可回原页逐行核对 |
| 文本SHA256 | 字符串 | 版本一致性与去重 |
| 审核状态 | 字符串 | 如 `OCR+人工目视校验` |

## 页签 2：列项明细（款级）

| 字段 | 说明 |
|---|---|
| 条号 | 所属条文 |
| 列项路径 | `1`、`2`、`3`；二级款写 `1.1` |
| 父项号 | 二级款才有 |
| 层级 | 1 / 2 |
| 该层正文 | 款文字 |
| 条号来源 | `原页编号` 或 `OCR推断`（**推断的必须标出来**） |
| 所属条小标题 | 冗余字段，方便单表查询 |

## 页签 3：表格明细（单元格级，长表）

| 字段 | 说明 |
|---|---|
| 表号 | `表7.4.1` |
| 表标题 | 用原表标题 |
| 所属条文 | 引用它的条文号 |
| 行号 / 列序号 | 坐标 |
| 列标题 | 表头 |
| 单元格值 | 值（不适用写 `—`，不写 0） |
| 来源 | `文字层` / `图片读图`。**决定该表读数的不确定度等级，必填** |
| 来源说明 | 文字层直接抽取 / 渲染图视觉转录（怎么读的） |
| 交叉校验 | 该表是否做过独立第二路径比对（`rapidocr 多重集比对一致` / `—（文字层，无需 OCR）`） |
| 转录提示 | 该表的存疑说明（原表内部矛盾、扫描缺笔、截断…）；**未改动原值，仅提示** |

> 「来源」「交叉校验」两列是复审工作台算不确定度的输入，不能省。
> 省了的结果：图片表格与文字层表格无法区分，复审队列只能按文档顺序排，等于没排。

## 页签 4：章节结构

`层级 | 编号 | 标题 | PDF起页 | 条文数 | 列项数 | 字数 | 条文号范围`

## 页签 5：RAG 切片（核心产出）

| 字段 | 说明 |
|---|---|
| 切片ID | 见下方 ID 规范 |
| 父条号 | 该切片所属的条文号（父块自己指向自己） |
| 切片层级 | `条文（父块）` / `款（子块·N）` / `表（子块·表X）` |
| 切片标题 | 小标题或表标题 |
| 切片全文 | **元数据头 + 换行 + 正文**，可直接嵌入 |
| 正文字符数 | |
| 估算token | 粗估：中文约 1.6 字符/token |
| PDF起页 / PDF末页 | |
| 切片SHA256 | |

### 切片 ID 规范

```
父块：GB55037-2022::2.1.2
子块：GB55037-2022::2.1.2#1        （第 1 款）
表格：GB55037-2022::7.4.1#表7.4.1
```

规则：`编号(去空格)::条号` + `#` + 层级标识。父块不带 `#`。

### 元数据头格式

```
《建筑防火通用规范》GB 55037-2022｜2 基本规定｜2.1 目标与功能｜第2.1.2条｜建筑防火目标｜第1款｜强制性条文
```

用 `｜`（全角竖线）分隔，全库统一。**头要一起建索引**——实测对按章节提问有收益。

## 页签 6-11

- **公式明细**（有公式时必选）：
  `公式编号 | 所属条文 | PDF页 | 规范化表达式（整理，非原文逐字） | LaTeX | 纯文本 | 正文处理 | 渲染图 | 可信度 | 存疑说明`。
  **原文列（语料库.条文原文本体）里始终保留裸占位 `〔公式（x）〕`**，保持原文保真、让交叉复核可比；
  **切片与导出 md 按「正文处理」分级落地**（v1.10.2）：
  - `写入正文`：高可信公式 → md 用 `$$…$$` + `> 纯文本：` 双写法，并带
    `〔公式（x）·整理式·非原文逐字·可信度高〕` 标记；切片用纯文本式。
  - `待核占位`：中/低可信公式 → 只留 `〔公式（x）·待核·未引入表达式〕` + 原因，
    **表达式不得出现在正文/切片/md**（防止还原值被当条文原文引用）。
  `纯文本` 必须由 `latex_to_plain` 从 `LaTeX` 生成（同源，保证两写法一致）；
  `渲染图` 记视觉转录所依据的裁图路径，供人工复核回查。
  校验：`formula_details.py --check`（分级 / 双写法 / 双向对账 / 与「式中」同父块）。
- **图表清单**（有图时必选）：`图表号 | 图表名称 | 所属条文 | PDF页 | 类型 | 内容说明`。
  图不做数值转录，只登记题注与"图里有什么"；诺模图/曲线类要在说明里写明"图内数值查不了"。
- **修订标记**（有局部修订下划线时必选）：`条文号 | PDF页 | 被下划线的原文行 | 被下划线文字（按段拆分） | 下划线x区间`。
  **一行内多段互不相连的下划线必须按段拆开并列**（`[段1]…｜[段2]…`），拼成一串会产生乱码。
- **页级元素**（必选）：`条文号 | PDF页 | 元素类型 | 原文行`。图题/图注/表题/表注这些行
  **保留在条文正文的原位置**（不挪动、不删除），同时单列登记，用于审计"哪些文字不是条文要求"。
  款正文必须是干净的要求句——断言：款正文不以 `图`/`表`/`注`/`附图`/`附表` 开头。
- **前置文件**：封面、公告、目次等非正文内容，单独存，不进语料库
- **字段说明**：每个字段的定义与边界，这个页签在汇报时特别有用，能证明"我们知道自己在做什么"
- **质检报告**：见 [quality-gates.md](quality-gates.md)；存疑清单要**机器可读**（维度/条号/严重度），
  供 `build_review_workbench.py` 消费

## 落地建议

- 条文号、块ID 一律用文本格式，导出时检查一遍有没有被 Excel 改成数字
- 切片全文里**不要**放未转义的 markdown 符号（表格用 `|` 渲染时可以，正文里避免）
- 所有"AI 归纳""OCR 推断"的产物都要有对应字段标注来源。这是规范类语料库的底线——**不能让人分不清哪句是原文**
